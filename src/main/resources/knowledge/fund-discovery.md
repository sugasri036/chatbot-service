
# Fund Discovery and NAV Guide

## 1. Exploring Mutual Funds

Investra provides a mutual fund discovery interface where users can browse available funds.

Users can:
- View the available mutual fund list.
- Search for funds.
- Filter funds by category.
- Sort funds by name.
- Sort funds by returns.
- Sort funds by NAV.

## 2. Fund Details

Selecting a fund opens its detailed information page.

The frontend displays available fund information such as:
- Fund name.
- Scheme code.
- Current NAV.
- Minimum investment amount.
- One-year return.
- Risk information.
- Historical NAV chart.

The displayed information depends on the data returned by Fund Service.

## 3. NAV Explained

NAV stands for Net Asset Value.

It represents the per-unit value of a mutual fund.

Example:

If a fund has an NAV of ₹50 and an investor purchases units worth ₹5,000:

Units = Investment Amount / NAV

Units = 5000 / 50

Units = 100

This is an illustrative calculation, not a guarantee of actual allotment.

## 4. Historical NAV Charts

Investra provides historical NAV charts with the following selectable periods:

- 1 month (1M)
- 6 months (6M)
- 1 year (1Y)
- 3 years (3Y)

These charts help users understand historical NAV movements.

Past NAV performance does not guarantee future returns.

## 5. Current NAV Updates

Fund Service stores fund information and NAV history.

The application uses an external NAV data provider to retrieve mutual fund NAV information.

A scheduled NAV update process is configured to run hourly when enabled.

The chatbot must not invent current NAV values.

Users should refer to the fund details page for the latest available NAV displayed by Investra.

## 6. Fund Discovery Process

1. Log in to Investra.
2. Open the fund discovery section.
3. Browse the available mutual funds.
4. Search for a particular fund if required.
5. Apply available category filters.
6. Sort the results using available sorting options.
7. Select a fund.
8. Review its NAV, returns, risk and historical chart.
9. Decide whether to proceed with an investment.

## 7. Investment Risk

Mutual funds carry market risks.

- Equity funds may experience significant price fluctuations.
- Debt funds carry interest-rate and credit risks.
- Historical returns are not guaranteed future returns.
- NAV movements can be positive or negative.

The chatbot should explain these concepts neutrally and must not guarantee profits.
